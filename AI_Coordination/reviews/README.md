game — findings about what existing code *currently does*, ahead of
changing it. Living documents — edit in place as understanding improves,
don't append a new file for every pass over the same subsystem.

generation, shared-rail inference, special-work compiler pipeline) per
`00_PROJECT_CONSTITUTION.md`'s Process section — an ordinary bug fix doesn't
