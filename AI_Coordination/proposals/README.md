# Proposals

One file per design decision for a non-trivial change to this mod (see
`00_PROJECT_CONSTITUTION.md`'s Process section for what needs one — ghost-
graph generation, shared-rail inference, and the special-work compiler
pipeline, in particular). Living documents — revise in place as the other
agent's investigation notes and challenges come in via `LOG.md`, don't fork
a new file per revision.

Ordinary bug fixes and small, well-scoped features don't need a proposal —
just do the work and record it in `LOG.md`.
